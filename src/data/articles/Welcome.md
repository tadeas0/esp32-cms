# Welcome

Welcome to state-of-the-art Content Management System powered solely by an ESP8266 chip. This CMS will allow you to create, edit and host your own microblog.

In order to manage the blog content and change CMS settings, you need to connect to the Access Point provided by the ESP8266. _It will be called **Blog Editor Access Point**, when you first boot up the CMS._

You can even use [links](./Second%20article.html).
